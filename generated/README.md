# Generated graph editions

`graph.dot` contains the full six-Age graph: 1,364 nodes and 3,239 non-disabled directed pairs. `myst_graph.pdf` presents that graph with publication framing.

The PDF retains the vector graph at native size and reproduces the original publication margins, Times-Roman title/subtitle, black border and linked footer. The footer dates this regeneration; it does not label a new game release. The formatting command and optional dependencies are documented in the [README](../README.md#add-the-publication-border-header-and-footer).

The DOT SHA256 is `c34e7bde44ba2896e9f047223014cc77e0c815bc51466c3907b9b57b593d7d02`. Framing changes no DOT or graph content.

The shortest/longest-path PDFs are the v1.01 editions of April 2025, kept unchanged. Their routes have the lengths the current generator computes, 24 and 130 edges, but they are drawn on the 2025 graph, which has no automatic next steps.
