## Confirmed defects

| Trigger | Previous behavior | Correction |
| --- | --- | --- |
| A nonempty stack manifest disagrees with its card XML files | A missing, extra or substituted card could be accepted silently; a missing destination could become a virtual node | Validate all declared IDs, including unnamed cards, against the imported inventory. Reject missing and unexpected IDs. Imports without an explicit manifest remain supported. |
| `SetNameMapping(nil)` followed by `AddNode` | Node insertion panicked when writing to the nil map | Normalize nil to a writable empty map, preserving fallback names and existing non-nil map semantics. |
| A custom path includes a disabled edge | Highlight styling concealed the edge's disabled state | Retain disabled styling and tooltip while highlighting. Restrictive tails keep their existing no-arrowhead convention. |
| A DOT input filename begins with `-` | Neato could interpret the filename as a command-line option | Resolve the input to an absolute path before invoking Neato. |
| Quoted decimal or negative card numbers | Numeric object positions could become named or virtual destinations | Reject the documented decimal/minus numeric syntax; retain ordinary literal-name resolution. Numeric positions remain unsupported. |
| A mandatory-waypoint route accumulates two finite weights whose sum overflows | It returned an infinite distance without an error, unlike an ordinary shortest-path query | Return an error when the complete route distance overflows; preserve finite route costs. |
| Rendering a small connected component | Layout sorting could reorder the caller's stored analysis slice | Copy the component before sorting it for display. |

Focused regressions reproduce these failures against the earlier code. Input-inventory tests cover complete, missing, empty, extra, substituted and manifest-free exports. The filename regression uses real Neato when available and checks that the output is a PDF.

## Rendering flow

`NewGenerator` stores the graph, metadata and default configuration. Each `Generate` call copies the requested path, resets node styles and stack colors, applies configured analysis, then writes graph attributes, component layout, sorted nodes and metadata edges.

Edge bookkeeping belongs to the render pass. `indexEdges` groups metadata occurrences under typed `(source, target)` keys and sorts those pairs numerically. Each occurrence owns its consumed flag, including repeated pointers to the same edge. Stable sorting preserves enabled/backtracking/disabled priorities and transitivity IDs. Reverse pairing consumes individual matching records; output order remains self-loops, merged reverse pairs, remaining ordinary edges and highlights last. Implied path transitions are emitted afterward.

This removes persistent derived edge and path maps, formatted string pair IDs, separate consumed-flag arrays, duplicate map-sorting helpers, a forwarding-only writer and an impossible internal error return. It does not replace necessary per-record matching with whole-pair merging. Node-label semantics remain unchanged, with explicit secondary-label coverage for analyzed stack and virtual nodes.
